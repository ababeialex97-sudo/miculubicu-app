# grandchef-campuri

Plugin mic, deja scris, care adaugă pe produse câmpurile cerute de plugin-ul GrandChef cu cheile exacte:

- `wccaf_id_grandchef` și `wccaf_cota_tva` (produse simple);
- `wccaf_id_grandchef_v` și `wccaf_cota_tva_v` (variații);
- câmpul „Preferințe” pe pagina produsului, salvat ca meta `Preferinte` pe linia de comandă.

Sursa lui încă nu e în repo. Copiază aici fișierele plugin-ului (din `wp-content/plugins/grandchef-campuri/` de pe server) ca să fie versionat.
